# App-Time | تایم

اپلیکیشن اندرویدی فارسی و RTL برای مدیریت آفلاین کسب‌وکار: پرونده مشتری، نوبت‌دهی، پرسنل و خدمات، پیام، امور مالی، یادآوری، باشگاه مشتریان و گزارش‌ها.

## وضعیت فعلی

نسخه فعلی: **2.0.0** (`versionCode = 3`)

- Android 8 به بالا (`minSdk = 26`)
- `targetSdk = 35`
- Kotlin + Jetpack Compose + Material 3
- دیتابیس داخلی SQLite
- رابط تیره RTL
- داده‌های اصلی بدون نیاز به اینترنت روی دستگاه ذخیره می‌شوند

## امکانات نسخه 2.0.0

- داشبورد واقعی بر اساس داده‌های دیتابیس
- پرونده مشتری: افزودن، نمایش، جستجو، ویرایش، حذف، یادداشت، تاریخ تولد و امتیاز وفاداری
- نوبت‌دهی: افزودن، ویرایش، حذف، وضعیت نوبت، خدمت، پرسنل، مدت، قیمت و تاریخ/ساعت
- پرسنل: نقش، شماره تماس، وضعیت فعال و مدیریت رکوردها
- خدمات: نام، مدت انجام و قیمت
- مالی و حسابداری: ثبت درآمد و هزینه، محاسبه مانده و گزارش
- صندوق پیام و ثبت سابقه مکالمات
- ارسال پیامک با `ACTION_SENDTO` و تأیید نهایی کاربر در برنامه پیامک دستگاه
- کمپین‌های محلی، تبریک تولد، بازگشت مشتری و قرعه‌کشی
- باشگاه مشتریان و امتیاز وفاداری
- رضایت‌سنجی مشتری با امتیاز و یادداشت
- یادآوری محلی نوبت و پیگیری با AlarmManager و Notification
- بازیابی Alarmها بعد از روشن‌شدن دستگاه
- Backup و Restore JSON
- تنظیمات اعلان، یادآوری، Provider پیامک، شماره اختصاصی، لینک رزرو و سایت
- پروفایل Drawer با نام و تصویر انتخابی
- بررسی آنلاین نسخه از `version.json`
- Back Stack واقعی و بازگشت مرحله‌ای
- منوی همبرگری سمت راست در RTL
- نمایش مبالغ با جداکننده هزارگان

## سرویس‌های وابسته به Backend

برنامه عمداً سرویس جعلی نمایش نمی‌دهد. موارد زیر برای اجرای تجاری واقعی به Backend یا Provider خارجی نیاز دارند:

- پنل پیامک خدماتی/منطقه‌ای و گزارش تحویل
- شماره اختصاصی پیامک
- رزرو عمومی چندکاربره از وب
- سایت اختصاصی میزبانی‌شده
- همگام‌سازی ابری چند دستگاه

کلید API سرویس‌های خارجی نباید داخل APK عمومی قرار بگیرد و باید در Backend امن نگهداری شود.

## معماری داده

- `data/AppDatabase.kt` — هسته SQLite، Schema، CRUD و Backup/Restore
- `data/AppController.kt` — واسط بین UI و دیتابیس و مدیریت State
- `data/Models.kt` — مدل‌های مشتری، نوبت، پرسنل، خدمت، مالی، پیام، یادآوری، رضایت و کمپین
- `notification/ReminderScheduler.kt` — اعلان‌ها، AlarmManager و بازیابی بعد از Boot
- `util/PersianDate.kt` — تبدیل تاریخ برای نمایش شمسی
- `util/FormatUtils.kt` — مبلغ، تاریخ و ارقام فارسی
- `util/UpdateChecker.kt` — بررسی نسخه جدید از GitHub
- `MainActivity.kt` — رابط Compose، Drawer و تمام صفحات کاربردی

## امضا و Update

`applicationId` ثابت برنامه `ir.asteam.apptime` است. برای اینکه نسخه جدید روی نسخه قبلی نصب شود، دو شرط باید همیشه رعایت شوند:

1. `versionCode` افزایش پیدا کند.
2. نسخه Publish با همان Release Keystore قبلی امضا شود.

Keystore، رمزها و فایل `keystore.properties` نباید در Repository عمومی Commit شوند.

## حریم خصوصی

داده‌های کسب‌وکار به‌صورت پیش‌فرض در SQLite داخل Sandbox برنامه نگهداری می‌شوند. Backup فقط با اقدام کاربر ایجاد یا بازیابی می‌شود.
