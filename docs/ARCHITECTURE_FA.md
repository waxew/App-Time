# معماری App-Time

## هدف
نسخه 1.0 پایه اندرویدی پروژه Time است و از ابتدا برای توسعه تدریجی و نصب نسخه‌های جدید روی نسخه قبلی طراحی شده است.

## اصول ثابت
- applicationId: `ir.asteam.apptime`
- افزایش `versionCode` در هر انتشار
- حفظ ساختار داده و مهاجرت دیتابیس در نسخه‌های بعد
- UI فارسی و RTL
- منوی همبرگری از سمت راست

## ماژول‌های نسخه پایه
- داشبورد
- پرونده مشتری
- نوبت‌دهی
- سامانه پیامک
- پرسنل و خدمات
- مالی و حسابداری
- گزارش سیستم
- تنظیمات و اعلان‌ها
- صفحات درباره ما، تماس با ما و درباره نرم افزار

## ادامه توسعه
در نسخه‌های بعدی لایه‌های Data/Repository، Room، سرویس پیامک، احراز هویت، API رزرو آنلاین و بررسی آنلاین نسخه به UI فعلی متصل می‌شوند. منطق شبکه از UI جدا باقی می‌ماند تا تعویض سرویس‌دهنده بدون بازنویسی صفحات امکان‌پذیر باشد.
